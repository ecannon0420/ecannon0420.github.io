<h1>HW 2: Roll-A-Ball</h1> 
<img src="https://jmu.instructuremedia.com/embed/10630c9c-da16-4501-a308-093318e7a0ac">
<p>The personal modification I made to my game was more aesthetic than functional. I just added some tree objects around the arena as decoration. Had I started a bit sooner, I could have made something that the player could interact with. Three takeaways from this project were:</p>
<ol>
    <li>Unity is a bit different from Godot (the only game engine I had used up to this point</li>
    <li>Connecting objects to other objects via tags and components will take some getting used to</li></p>
    <li>Empty GameObjects are perfect for staying organized</li>
</ol>
<p>I think that by doing this tutorial, I'm starting to see how to make interactive environments that the user can explore. This will allow me to create spaces where the person viewing the story can use objects or scenes around them to further shape their experience.
